# Emotion Terminal

## Setup
1. Copy `config.template.js` to `config.js`
2. Add your GLHF API key to `config.js`
3. Copy `system_prompt.template.js` to `system_prompt.js`
4. Add your system prompt to `system_prompt.js`
5. Do not commit `config.js` or `system_prompt.js` to version control

## Environment Variables
- `API_KEY`: Your GLHF API key (required)

## System Prompt
The system prompt defines the AI's personality and behavior. Keep this secure and do not share it publicly.
